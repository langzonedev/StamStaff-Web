# Prototype Privacy and Data Guidance

This public repository and any early static prototype must use fictional data only.

Do not enter or commit:

- real employee or customer names, email addresses, phone numbers, availability, assignments, or evaluations;
- credentials, tokens, provider identifiers, or internal URLs;
- private eligibility/allocation logic, legal analysis, incidents, or operating procedures.

Before any real-user pilot, the private project must approve identity and access control, data collection purpose, retention/deletion, provider/subprocessor treatment, data region, logging, incident ownership, privacy notice, account revocation, backup/restore, and customer consent/authority. A public clickable prototype is not approved to process real roster data merely because it is reachable online.
